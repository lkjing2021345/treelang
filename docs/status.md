# 玩家状态系统（躯体 / 精神 双轴）

> 本系统将玩家状态拆解为 **【命】（躯体/HP）** 与 **【灵】（精神/SAN）** 两个独立维度。  
> 每个维度包含 3 个递进阶段，共同组成 6 种核心状态。  
> 状态名称均已替换原模糊命名，并贴合“咒术/克苏鲁”世界观。

---

## 一、 躯体状态轴（命 · 血量相关）

| 原命名 | 新命名 | 触发阈值 | 具体机制 | 恢复方式 | 叙事/UI表现 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 健康 | **【命·无垢】** | HP > 60% | 全属性正常。无任何负面修正。 | — | 角色呼吸平稳，UI边框为洁净的淡白色。 |
| 受伤 | **【命·创痕】** | 30% < HP ≤ 60% | **攻击力下降 10%**，**护盾恢复速度减半**。 | 使用回复道具、特定回血术式、在补给点休息。 | 角色身上出现裂痕/血迹，UI边框变为暗红色，伴有微弱的心跳音效。 |
| 濒死 | **【命·残烛】** | HP ≤ 30% | **移动速度降低 20%**（在 MUD 中体现为行动回合消耗增加），**受到伤害额外增加 15%**。若 HP 归零，立即触发【死亡结局】。 | 仅能通过高级回复道具或特殊事件（如NPC舍身救治）恢复。 | 屏幕边缘出现碎裂血纹，画面色调转为黑白，呼吸声沉重且不规则。 |

## 二、 精神状态轴（灵 · SAN 值相关）

| 原命名 | 新命名 | 触发阈值 | 具体机制 | 恢复方式 | 叙事/UI表现 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 生病 | **【灵·侵染】** | 40 < SAN ≤ 70 | 偶尔出现**视觉噪点**或**幻听**（如虚假的脚步声、低语）。**NPC交谈成功率下降 15%**。 | 使用“憩息”指令、与理智更高的NPC交谈（转移理智）、使用特定净化道具。 | 画面出现细微的扭曲波纹，UI边框呈浑浊的墨绿色。 |
| 疯狂 | **【灵·暴走】** | 10 < SAN ≤ 40 | 进入 **“失控”状态**（符合原设计）：无法使用属性条数 ≥ 3 的复杂术式；商店价格飙升 **100%**；战斗中每回合有 **20% 概率** 自动攻击随机目标（敌我不分）。 | 必须通过特殊事件或高稀有度道具（如“静谧圣水”）恢复至 40 点以上。 | UI边框出现旋转的黑色裂纹，屏幕四周有暗影触手蠕动画效果，背景音乐走调。 |
| 濒死（精神） | **【灵·残息】** | 1 ≤ SAN ≤ 10 | **每移动一步（或每经过 3 个战斗回合）**，有 **40% 概率** 陷入“恍惚”（跳过当前行动回合）。**理智自然恢复完全停止**。 | 只能通过极稀有道具（如“古神之泪”）或特定剧情抉择（献祭某张术式卡）恢复至 10 点以上。 | 屏幕被大面积的黑暗笼罩，仅角色周围有微弱光晕，所有NPC对话显示为“？？？”。 |
| 疯狂致死 | **【灵·绝寂】** | SAN = 0 | **精神死亡**。玩家角色彻底丧失自我意识，**游戏立即进入【疯狂致死·特殊结局】**（该结局视为一种失败，但会解锁专属成就与永久奖励）。 | **不可恢复**（除非开启特定“新游戏+”模式）。 | 屏幕完全黑屏，只有一行白字缓缓浮现：“你听见了深渊的回应。它记住了你。” |

## 三、 双轴叠加态（进阶交互逻辑）

当 **躯体状态** 与 **精神状态** 处于不同阶段时，会产生额外的 **耦合效果**（增加策略深度）：

| 躯体状态 | 精神状态 | 耦合效果（额外规则） |
| :--- | :--- | :--- |
| **命·创痕**（受伤） + **灵·侵染**（生病） | **脆弱共鸣**：受到的单次伤害额外 +10%（痛觉与精神痛苦互相放大）。 |
| **命·残烛**（濒死） + **灵·暴走**（疯狂） | **绝境逆火**：虽然无法使用复杂术式，但简单术式（1~2条属性）的基础伤害提升 **30%**（本能求生）。 |
| **命·无垢**（健康） + **灵·残息**（精神濒死） | **空壳之躯**：物理防御力提升 20%，但每回合自动流失 2% 最大咒力（肉体无伤，精神早已涣散）。 |
| **命·残烛**（濒死） + **灵·绝寂**（疯狂致死） | **强制终局**：直接跳过濒死判定，立即触发双重结局【肉灵俱灭】（最强即死组合，但会解锁最高级别隐藏成就）。 |

## 五、 旧名称与新名称对照表（开发日志）

| 原模糊名称 | 新名称（归属） | 变更理由 |
| :--- | :--- | :--- |
| 健康 | 命·无垢 | 区分“精神健康”与“肉体健康”，更精准。 |
| 受伤 | 命·创痕 | 强调躯体伤痕的积累感。 |
| 生病 | 灵·侵染 | 明确指向 SAN 值污染，非肉体病菌。 |
| 疯狂 | 灵·暴走 | 突出“失控”这一关键机制，便于玩家理解惩罚逻辑。 |
| 濒死（原归类 SAN） | 灵·残息 | 与原 HP 濒死“命·残烛”形成双轴对称，且仅差一字，便于区分（一个是肉身灭，一个是精神灭）。 |
| 疯狂致死 | 灵·绝寂 | 更具“不可逆的终结感”，贴合克苏鲁式精神消亡美学。 |
