# Boss 设计文档 · 深渊古神（五阶段完全版）

> 本 Boss 为当前楼层最终首领，贯穿整条主线。  
> 战斗分为五个阶段，每削减 1000 HP 进入下一阶段。  
> 每个阶段拥有独特的机制与技能组，且与自身元素意象深度绑定。

---

## 基础信息

| 项目 | 内容 |
| :--- | :--- |
| **名称** | 深渊古神（五形态） |
| **总生命值** | 5000 |
| **阶段切换条件** | 每损失 1000 HP 进入下一阶段 |
| **阶段顺序** | 石躯之茧（风）→ 冰骸之胎（土）→ 熔核之腑（水）→ 风腔之喉（火）→ 虚影之核（光） |
| **被克制属性** | 各阶段对应：风、土、水、火、光（末阶段弱光） |

---

## 阶段一 · 深渊古神·石躯之茧

> *“它尚未苏醒，只是一座坟丘。但坟丘会呼吸。”*

### 初始状态
- Boss 处于 **【沉眠】** 状态，拥有 **100 点初始护盾**。
- 每回合开始时，护盾自动恢复 **100 点**（上限 300）。

### 技能组

| 技能名称 | 效果 | 触发逻辑 |
| :--- | :--- | :--- |
| **咒·岩铠复苏** | 每回合开始时，恢复 100 点护盾（不超过 300）。若护盾已满，则改为恢复 50 HP。 | 固定触发（每回合开始） |
| **咒·震裂回响** | 对玩家造成 20 点伤害，并施加 1 层 **【咒·砂缚】**。每层使玩家闪避率下降 5%，最多叠 5 层。 | 常规攻击行动（70% 概率） |
| **咒·山岳吐息** | 消耗全部护盾（至少 100 点），对玩家造成 **护盾值 × 0.8** 的真实伤害。若护盾低于 100，则此技能不可用。 | 特殊行动（护盾 ≥ 100 时 30% 概率） |
| **咒·千钧之眠** | 若玩家处于 **【黑闪】** 状态，Boss 立即对玩家施加 1 层 **【咒·虚弱】**：造成的所有伤害降低 15%，持续 2 回合。 | 被动触发（玩家黑闪时） |

### 机制核心
- **护盾博弈**：玩家可以选择**快速破盾**让 Boss 少放“山岳吐息”，也可以选择**保留护盾**等 Boss 自己消耗掉来换取其他收益。
- **砂缚层数**：叠满 5 层时，玩家闪避归零，逼迫玩家携带净化手段或改变战术。

## 阶段二 · 深渊古神·冰骸之胎

> *“石壳剥落，脐带垂落。它在吮吸地底的冷。”*

### 入场效果
- 进入此阶段的首个回合，Boss 自动对玩家施加 **【咒·霜足】**：行动回合消耗 +50%（持续 3 回合，不可净化）。

### 技能组

| 技能名称 | 效果 | 触发逻辑 |
| :--- | :--- | :--- |
| **咒·霜足** | 对玩家施加“霜足”：累计跳过玩家 **2 次行动回合** 后消失。霜足完全消失后，间隔 2 回合才能再次施加。 | 入场固定施加一次；之后根据冷却规则触发（BOSS 行动时，若霜足已消失且冷却结束，70% 概率使用） |
| **咒·脐带汲魂** | 对玩家造成 25 点伤害，并恢复 Boss 等量 HP。 | 常规攻击行动（60% 概率） |
| **咒·冰茧孵化** | Boss 给自己施加 1 层 **【冰茧】**（最多 3 层）。每层使 Boss 受到伤害降低 10%。每回合结束时，若 Boss 持有冰茧，则消耗 1 层并对玩家造成 15 点伤害。 | 特殊行动（每 3 回合至少使用一次） |
| **咒·永冻哀嚎** | 若冰茧层数 ≥ 2，Boss 消耗 2 层冰茧，对所有玩家造成 40 点伤害，并施加 **【咒·颤栗】**：下回合伤害减半。 | 当冰茧层数 ≥ 2 时，替代普攻（40% 概率） |

### 机制核心
- **冰茧双刃剑**：Boss 自己叠减伤，但叠高了会触发范围大招。玩家需要判断是**继续输出**（硬吃减伤）还是**拖延等 Boss 放完大招**再爆发。
- **霜足惩罚**：行动变慢会严重影响心流连击的节奏，考验玩家的资源管理。

## 阶段三 · 深渊古神·熔核之腑

> *“冰躯褪尽，液态火核裸露。每一次搏动，都是一次邀请。”*

### 入场效果
- 进入此阶段的首个回合，Boss 对玩家施加 **【咒·焚身】**：玩家回合结束时，受到 8 点火焰伤害（持续至战斗结束，可被水属性术式暂时压制）。

### 技能组

| 技能名称 | 效果 | 触发逻辑 |
| :--- | :--- | :--- |
| **咒·焚身** | 玩家回合结束时受到 8 点伤害（无视护盾）。若玩家使用水属性术式，本回合此伤害减半。 | 入场固定施加，持续整场战斗 |
| **咒·熔核脉动** | 对玩家造成 30 点伤害，并施加 1 层 **【咒·灼印】**（最多 5 层）。每层使玩家受到的火焰伤害 +3。 | 常规攻击行动（65% 概率） |
| **咒·焦油之潮** | Boss 喷出黑色焦油，对玩家造成 20 点伤害，并施加 **【咒·粘滞】**：下回合无法使用属性条数 ≥ 3 的术式。 | 特殊行动（每 2~3 回合使用一次） |
| **咒·地核献祭** | Boss 燃烧自身，扣除 100 HP，但永久提升 **10 点基础攻击力**（可叠加，无上限）。同时清除自身所有减益效果。 | 当 Boss HP > 1000 时，每 4 回合至少使用一次 |

### 机制核心
- **献祭成长**：这是“仪式”思路的扩展版——Boss 会主动烧血换永久增伤，打持久战会越来越难。
- **火伤叠加**：灼印层数越高，焚身的每回合扣血越痛，逼迫玩家尽快进入下一阶段。
- **水属性对策**：使用水属性术式可以压制焚身伤害，鼓励玩家准备水属性牌。

## 阶段四 · 深渊古神·风腔之喉

> *“熔核炸裂，化作无定的风。它不再有形体，只剩下吞咽。”*

### 入场效果
- 进入此阶段的首个回合，Boss 获得 **【咒·风暴之仪】**：每回合结束时，Boss 永久提升 8 点攻击力（可叠加）。
- 同时，玩家获得 **【咒·逆息】**：所有治疗效果降低 30%（持续至战斗结束）。

### 技能组

| 技能名称 | 效果 | 触发逻辑 |
| :--- | :--- | :--- |
| **咒·风暴之仪** | 每回合结束时，Boss 攻击力永久 +8。此效果不可驱散。 | 入场获得，被动每回合触发 |
| **咒·真空噬咬** | 对玩家造成（35 + 当前仪式层数 × 3）点伤害。 | 常规攻击行动（70% 概率） |
| **咒·风眼坍缩** | 当 Boss 仪式层数大于4时有概率触发，Boss 清空所有仪式层数，对本回合造成 **仪式层数 × 12** 点真实伤害，并施加 **【咒·迷途】**：下回合玩家有 50% 概率随机选择目标（敌我不分）。 | 特殊行动（仪式层数 ≥ 5 时可用） |
| **咒·逆鳞回响** | 若玩家在本回合使用风属性术式，Boss 立即反击，造成 25 点伤害，并额外增加 1 层仪式层数。 | 被动触发（玩家使用风属性时） |

### 机制核心
- **时间炸弹**：仪式层数无限叠加，Boss 普攻越来越痛，同时会在层数高时释放大招“风眼坍缩”——这是一个 **“越拖越痛，但提前释放大招会清空层数”** 的博弈。
- **属性惩罚**：玩家用风属性打 Boss 会被额外反噬，但 Boss 弱的是火，风不克制它反而被克制（火克风，所以这里 Boss 是风系，玩家应该用火）。
- **迷途风险**：大招附带混乱效果，配合心流机制会非常刺激——你可能刚续上连击，下一回合就打到自己了。

## 阶段五 · 深渊古神·虚影之核

> *“没有形体，没有声音。只有无数双眼睛，注视着你自己的恐惧。”*

### 入场效果
- Boss 变为 **【不可选定】** 状态（无法被直接攻击），同时召唤 **4 个“虚影之眼”** 环绕自身。
- 每个虚影之眼对应一种 Debuff：**砂缚、霜足、灼印、迷途**。
- 玩家必须先击破虚影之眼（每个 200 HP），才能对 Boss 本体造成伤害。

### 技能组

| 技能名称 | 效果 | 触发逻辑 |
| :--- | :--- | :--- |
| **咒·四象凝视** | 每回合开始时，Boss 随机选择 1 个存活的虚影之眼，对玩家施加其对应的 Debuff（持续 2 回合）。若所有虚影之眼均已击破，则本技能失效。 | 固定触发（每回合开始） |
| **咒·暗影之球** | 若玩家身上同时存在 **4 种 Debuff**，Boss 立即释放暗影之球，造成 **24 × 本场战斗中暗影之球已触发次数** 点真实伤害（上限120点伤害），然后清除玩家所有 Debuff。 | 被动触发（检测到 4 Debuff 同时存在时） |
| **咒·虚空坍缩** | 对玩家造成 40 点伤害，并随机移除玩家身上 1 个增益效果（如护盾、心流层数等）。 | 常规攻击行动（50% 概率，仅当至少 1 个虚影之眼存活时） |
| **咒·终焉回响** | 若所有虚影之眼均被击破，Boss 进入 **【曝露】** 状态，受到的伤害提升 50%，但每回合会对玩家造成 15 点真实伤害（不可减免）。 | 被动触发（虚影之眼全部击破后） |
| **咒·禁忌之瞳** | Boss 睁开一只巨大的苍白之眼，**随机禁用玩家 1 张术式卡**（本回合内无法使用，被禁用的卡牌在玩家手牌中显示为灰色锁闭状态）。<br><br>**禁用规则**：<br>• 优先禁用玩家 **当前手牌中** 的术式卡。<br>• 被禁用的术式卡 **本回合无法释放**，下回合开始时自动解锁。<br>• 若玩家当前手牌中 **全部术式卡均被禁用**，则本回合只能使用普通攻击（造成 5 点固定伤害，无属性）。 | 仅当 **至少 1 个虚影之眼存活** 时，Boss 有 **40% 概率** 替代普通攻击使用此技能。<br><br>**冷却**：每 3 回合最多触发一次。 |

### 机制核心
- **Debuff 管理**：四种 Debuff 集齐 = 秒杀级大招（暗影之球），但清除后 Boss 下次大招威力会更高（因为是“触发次数”累计）。玩家要在“清 Debuff”和“硬吃小伤害”之间做选择。
- **虚影之眼优先级**：四个小眼本身有血量，先打哪个取决于玩家当前最怕哪个 Debuff。
- **曝露双刃剑**：击破全部小眼后 Boss 易伤，但玩家也会每回合被真实伤害磨血——这正是你原设计中“光阶段每次攻击挂一个 Debuff”的进化版，增加了策略纵深。

## Boss 技能状态机判定顺序（全阶段统一规则）

> 每个回合开始时，Boss 按照以下 **优先级从高到低** 依次检查技能触发条件。  
> 一旦某个技能判定为 **“触发”**，Boss 立即执行该技能，并 **跳过本轮后续所有主动技能判定**。  
> **被动类技能**（如“咒·千钧之眠”“咒·逆鳞回响”）不占用行动回合，在条件满足时 **独立触发**，不与主动技能冲突。

---

### 优先级总表（由高到低）

| 优先级 | 技能类型 | 说明 |
| :---: | :--- | :--- |
| **P0** | 强制入场 / 阶段切换技能 | 进入新阶段时固定触发，不占用行动回合，优先于一切判定。 |
| **P1** | 特殊条件大招（消耗资源型） | 需要消耗层数/资源才能释放的技能（如“山岳吐息”“永冻哀嚎”“风眼坍缩”）。一旦条件满足，**必定优先释放**。 |
| **P2** | 特殊行动（定时/冷却型） | 有固定冷却回合或定时触发的技能（如“冰茧孵化”“地核献祭”）。若冷却已就绪，则此优先级触发。 |
| **P3** | 常规攻击（概率型） | 按概率判定的普通攻击技能（如“震裂回响”“脐带汲魂”“熔核脉动”“真空噬咬”）。多个概率技能同时满足时，按技能表中排列顺序依次判定，**第一个判定成功的执行**。 |
| **P4** | 保底攻击 | 若以上所有技能均未触发，则执行一次 **基础物理攻击**（造成 15~20 点固定伤害，无特殊效果）。 |

### 设计说明

| 设计点 | 说明 |
| :--- | :--- |
| **互斥性** | 每个回合 Boss 只会执行 **1 个主动技能**（P1~P4 中最多一个），避免了“多个技能同时发动”的混乱。 |
| **被动独立** | P0 类技能（回盾、焚身、风暴之仪、四象凝视、终焉回响等）不占用行动回合，与主动技能 **叠加生效**。 |
| **插队机制** | “暗影之球”属于检测到条件后 **立即强制触发**，优先级甚至高于 P1，但放在 P0 区域以作区分。 |
| **概率判定顺序** | 当多个 P3 概率技能存在时，按技能表中 **从上到下** 的顺序依次判定，第一个成功的执行，后续不再判定。 |
| **保底保障** | P4 确保 Boss 每个回合至少会做出一次有效行动，不会出现“无事发生”的情况。 |
