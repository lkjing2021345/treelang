风火水土光五种，暂时没有特殊技能

# 咒蚀系术式（毒性 / 诅咒术式）

---

## 一、通用限制（所有咒蚀系术式共有）

- **元素属性列表**：`[]`（空）
- **黑闪判定**：永不触发。
- **心流熔断判定**：若在 **心流激活状态** 下释放本系术式，视为传导属性为空，与上一回合钥匙无交集，**立即中断心流**并触发【术式熔断】。熔断惩罚对象包含本术式，惩罚回合数按主文档规则计算。
- **怪物抗性（古神之鳞）**：Boss 与精英怪每受到一次咒蚀系术式伤害，后续咒蚀系术式对该目标的伤害 **永久递减 15%**（可叠加，最低降至原伤害的 10%）。该抗性对普通小怪无效。

## 二、术式详表

### 1. 蚀骨衰亡

| 项目 | 内容 |
| :--- | :--- |
| **标签** | 持续压血 |
| **基础机制** | 基于敌人当前生命值百分比造成伤害 |
| **咒力消耗** | 20 点 |
| **冷却回合** | 3 回合 |
| **伤害公式** | • 若敌人当前血量 > 最大血量的 60%：`当前血量 × 8%` <br> • 若敌人当前血量 ≤ 最大血量的 60%：`当前血量 × 4% + 攻击力 × 0.5`（固定数值） |
| **心流加成** | 最终伤害 × 当前心流累计倍率 |
| **战术定位** | 中前期对抗高血量敌人（Boss 阶段一、二）时压血线，后期有保底数值避免刮痧。 |

---

### 2. 裂魂断罪

| 项目 | 内容 |
| :--- | :--- |
| **标签** | 斩首限伤 |
| **基础机制** | 基于敌人最大生命值上限百分比造成伤害 |
| **咒力消耗** | 80 点（极高） |
| **冷却回合** | 5 回合 |
| **伤害公式** | • 对 Boss / 精英：`最大血量 × 3%` <br> • 对普通小怪：`最大血量 × 1.5%`（减半） |
| **心流加成** | 最终伤害 × 当前心流累计倍率 |
| **特殊限制** | 每场战斗 **仅可释放一次**，释放后本场战斗该术式被封印，无法再次使用。 |
| **战术定位** | Boss 战终盘的斩杀大招，高咒力与单次限制防止跳阶段。 |

---

### 3. 虫噬回响

| 项目 | 内容 |
| :--- | :--- |
| **标签** | 层数波动（清杂特化） |
| **基础机制** | 基于叠层数造成固定伤害，层数每回合自然衰减 |
| **咒力消耗** | 35 点 |
| **冷却回合** | 2 回合 |
| **初始层数** | `x = 1 + floor(敏捷 / 5)`（向下取整，最低为 1） |
| **伤害公式** | 本回合造成 `x` 点伤害（受心流倍率加成） |
| **层数变化（回合结束时）** | • 正常衰减：`x -= 1`（降至 0 后不再变化） <br> • 若本回合释放了任意元素术式并 **成功触发黑闪**（延续心流），则 `x += 1`（不衰减，反增） |
| **隐藏豁免（清杂判定）** | **若本术式直接击杀目标**，本次行动 **不计入心流链路**（即不触发术式熔断，也不污染元素术式的冷却记录）。 |
| **战术定位** | 小怪房清杂神技，低咒力短冷却；Boss 战乏力，适合作为断连过渡填充。 |

---

### 4. 血祭逆鳞

| 项目 | 内容 |
| :--- | :--- |
| **标签** | 自残搏命 |
| **基础机制** | 基于玩家当前生命值造成伤害，同时反噬自身 |
| **咒力消耗** | 0 点（免费） |
| **冷却回合** | 1 回合 |
| **伤害公式** | • 对敌人：`玩家当前血量 × 15%`（受心流倍率加成） <br> • 对自身：`该伤害 × 30%` 的 **真实伤害**（无视护盾，直接扣血） |
| **释放限制** | 仅当玩家当前血量 **大于** 最大血量的 50% 时方可释放。 |
| **战术定位** | 高血量构筑下的极限爆发，与【耐力】属性博弈；残血禁用，防止雪崩。 |

## 三、成就联动（永久奖励）

若游戏内已实现成就系统，以下两项可作为本系术式的专属解锁奖励：

- **【以血换血】**  
  累计使用“血祭逆鳞”自损 5000 血量后解锁。  
  **奖励**：称号《狂徒》——血祭逆鳞的自损比例永久降低至 **25%**。

- **【虫群之心】**  
  单次战斗中“虫噬回响”叠层超过 10 层后解锁。  
  **奖励**：特殊被动《虫巢》——虫噬回响的衰减速度减半（每 **两** 回合减 1 层）。

## 四、战术备忘（供玩家参考）

| 局面 | 推荐使用术式 | 注意事项 |
| :--- | :--- | :--- |
| 战斗起手，心流未启动 | 蚀骨衰亡 / 裂魂断罪 | 无熔断风险，放心压血或斩上限。 |
| 心流自然中断后的过渡回合 | 虫噬回响 | 低消耗填充伤害，顺便叠层。 |
| Boss 战残血（<30%） | 裂魂断罪（若未使用） | 单次封印，务必留到最关键时刻。 |
| 自身血量健康，且需要爆发 | 血祭逆鳞 | 注意自损真实伤害，护盾不挡。 |
| 清小怪房，追求效率 | 虫噬回响 | 击杀目标时不触发熔断，可放心收尾。 |
| **心流已启动，且不想断连** | **禁用所有咒蚀系术式** | 强行使用将熔断并惩罚所有参与连击的术式，后果严重。 |
